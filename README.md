# c-study

C언어를 독학하면서 직접 작성한 예제 코드들을 기록하는 저장소입니다.

## 학습 목표

- C언어 기본 문법 이해
- 배열, 반복문, 조건문 구조 익히기
- 직접 문제를 풀면서 코드 흐름 감각 만들기
- 나중에 보안, 시스템, 리버싱 공부로 확장하기

## 파일 목록

### main.c

원하는 정수 범위를 입력받고, 원하는 두 수의 배수들의 총합을 구하는 프로그램입니다.

사용한 개념:

- `scanf`
- `printf`
- `for`문
- `if`문
- 나머지 연산자 `%`

### score_sort.c

학생 5명의 점수를 입력받고, 점수가 높은 순서대로 정렬하여 출력하는 프로그램입니다.

특징:

- 점수 배열 `b[]`를 내림차순으로 정렬
- 학생 번호 배열 `d[]`도 점수와 함께 교환
- 점수와 학생 번호가 따로 놀지 않도록 처리
- 버블 정렬과 비슷한 방식으로 직접 구현 (정렬 로직 학습한 적 없음)

사용한 개념:

- 배열
- 중첩 반복문
- `if`문
- 변수 교환, swap
- 내림차순 정렬
